# Advisor-ready figure index

All figures in this directory are generated by
`scripts/build_advisor_ready_figures.py` from committed authoritative CSVs.
SVG is the archival/vector output; PNG is the presentation preview.

| Figure | Available files | Authoritative source |
|---|---|---|
| MAIN-VAL / MAIN-TERM paired Stage-1 to Stage-2 forest | `mainstream_stage1_stage2_forest.svg`, `.png`, and `mainstream_stage1_stage2_forest_data.csv` | `experiment_tracking/experiment_statistics.csv` |
| PW Kmin=3 30-minute coverage sensitivity | `pw_kmin3_30min_coverage.svg`, `.png`, `pw_kmin3_30min_sensitivity.csv`, and `pw_kmin3_over_30m_instances.csv` | `experiment_tracking/mcts_progressive_widening_sensitivity/kmin3_runtime_jobs.csv` and `kmin3_success_runtime_instances.csv` |
| PW Kmin=3 successful-instance runtime ECDF | `pw_kmin3_success_runtime_ecdf.svg` and `.png` | `experiment_tracking/mcts_progressive_widening_sensitivity/kmin3_success_runtime_instances.csv` |
| Drone MAIN-TERM paired policy/MCTS endpoints | `drone_mainterm_policy_mcts.svg` and `.png` | `experiment_tracking/drone_endpoint_mcts_paired_results.csv` |

The 30-minute PW result is a deterministic counterfactual over recorded
successful-instance runtimes: a success is removed when its recorded runtime
exceeds 1,800 seconds. It is not a fresh capped execution. Policy whole jobs
finished in minutes, but the historical policy evaluator did not record
per-instance elapsed time.

Existing MPrime validation artifacts remain under
`experiment_tracking/mprime_validation_ipc_scale_v1/`, including
`corrected_learning_curves.svg`, `.png`, and the corresponding aggregate CSV.

Zenotravel's now-complete PRESERVE-4 paired endpoint table is
`experiment_tracking/four_domain_preservation/zenotravel_stage2_comparisons.csv`.
Delivery and TPP remain live, so the combined PRESERVE-4 figure is intentionally
not frozen yet.
